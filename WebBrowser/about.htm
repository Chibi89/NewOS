NewOS Web Browser v1.0 (64-bit Edition)

Browser web grafico nativo, client HTTP e motore di rendering HTML per NewOS V1.

Specifiche Tecniche

  • Architettura: Monolitica x86_64 Long Mode, conforme alla System V AMD64 ABI.
  • Protocolli di Rete: HTTP 1.0/1.1 su socket stream TCP/IP porta 80.
  • Scheda di Rete Attiva: Intel PRO/1000 Gigabit o Realtek RTL8139 con lease DHCP.
  • Motore HTML: Tokenizer ed interprete dei tag HTML 1.0 e 2.0 (H1-H3, A, P, BR, HR, B, I, UL, OL, LI, PRE).
  • File System Locale: Supporto completo per il caricamento diretto da partizione exFAT (file:///C:/).

Guida all'Uso

Per navigare su un sito o pagina locale:

  1. Inserisci l'indirizzo nella barra in alto (es. http://95.141.32.1 oppure about:home).
  2. Premi il tasto Invio oppure fai clic sul pulsante [ Vai ].
  3. Utilizza i pulsanti [<] Indietro e [>] Avanti per spostarti nella cronologia delle pagine visitate.
