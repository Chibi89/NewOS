NewSoft Web Browser v1.0 (64-bit Edition)

Browser web grafico nativo, client HTTP e motore di rendering HTML/CSS per NewOS V1.

Specifiche Tecniche

  • Architettura: Monolitica x86_64 Long Mode, conforme alla System V AMD64 ABI.
  • Protocolli di Rete: HTTP 1.0/1.1 su socket stream TCP/IP porta 80.
  • Scheda di Rete Attiva: Intel PRO/1000 Gigabit o Realtek RTL8139 con lease DHCP.
  • Motore HTML/CSS: Parser semantico HTML5 con elementi strutturali, video player, stili e colori.
  • File System Locale: Supporto completo per il caricamento diretto da partizione exFAT (file:///C:/).

Motore di Rendering e Crediti

L'architettura del motore di impaginazione e rendering e' basata sui principi e standard aperti del progetto open-source NetSurf Browser Engine (C89/C99), ottimizzato per l'interfaccia grafica e il kernel a 64-bit di NewOS V1.

@credits & @thanks: NetSurf Project Team (www.netsurf-browser.org).

Guida all'Uso

Per navigare su un sito o pagina locale:

  1. Inserisci l'indirizzo nella barra in alto (es. http://youtube.it oppure about:home).
  2. Premi il tasto Invio oppure fai clic sul pulsante [ Vai ].
  3. Utilizza i pulsanti [<] Indietro e [>] Avanti per spostarti nella cronologia delle pagine visitate.
